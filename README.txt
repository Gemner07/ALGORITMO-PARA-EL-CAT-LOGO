PROYECTO: ALGORITMO PARA EL CATÁLOGO

Requisitos:
- Python 3
- Tkinter (normalmente viene con Python)

Cómo ejecutar:
1. Mantener todos los archivos en la misma carpeta.
2. Abrir una terminal dentro de la carpeta.
3. Ejecutar: python app.py
   (También se puede usar python main.py)

Funciones principales:
- Registrar productos.
- Consultar el catálogo.
- Buscar por código o descripción.
- Actualizar datos y stock.
- Eliminar productos.
- Mostrar stock crítico menor a 10 unidades.
- Ordenar productos alfabéticamente.
- Guardar y recuperar datos en catalogo.txt.

Pruebas:
- Ejecutar: python pruebas.py
